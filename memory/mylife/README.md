# My Life Memory

Dave wants life-history/story material he shares to be remembered and collated by year in the My Life / Mission Control area.

- Use `memory/mylife/YYYY.md` for dated facts.
- Use `memory/mylife/undated.md` when the year is unclear.
- Use `memory/mylife/thankful-for-people.md` for Dave's living list of people he is grateful to have known, including context, contact clues, and possible notes to send.
- Preserve Dave's voice for later memoir material.
