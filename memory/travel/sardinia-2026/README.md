# Sardinia Trip 2026

Working travel folder for Dave's upcoming Sardinia trip.

## Purpose

- Save travel documents Dave sends.
- Extract flight, lodging, transportation, reservation, and date details.
- Build and maintain a practical itinerary.
- Support trip-time questions about flight times, local logistics, trains, restaurants, and things to do.

## Folders

- `documents/` - original travel documents and saved source files.
- `expenses/` - local trip expense account, ledger, and receipt image copies.
- `itinerary/` - working itinerary and summaries.
- `notes/` - local recommendations, logistics notes, and trip-time updates.

## Boundaries

- Local organization and itinerary drafting are okay.
- Bookings, cancellations, purchases, external messages, or modifications to shared/cloud files require Dave's explicit approval first.
